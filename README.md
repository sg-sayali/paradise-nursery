# Paradise Nursery

Paradise Nursery is an online plant shopping application where users can explore houseplants, add plants to a shopping cart, manage quantities, and view the total cost.

## Features
- Browse plants by category
- View plant names, images, and prices
- Add plants to the cart
- Update quantities and remove items
- View the shopping cart total

## Technologies
- React
- Redux Toolkit
- React Redux
- CSS
- Vite
